# CA Trainer for GitHub Pages

Готовый статический тренажёр для программы CA.

Структура пакета:
- `index.html` — интерфейс тренажёра
- `questions.js` — банк вопросов
- `assets/images/` — изображения для вопросов

Как обновлять без смены ссылки:
1. Оставляйте тот же репозиторий и тот же путь к `index.html`.
2. Заменяйте `questions.js`.
3. Если добавляются новые изображения, загружайте их в `assets/images/`.
4. Делайте commit — ссылка GitHub Pages останется прежней.

Важно:
- Для вопросов с изображениями путь в банке должен быть таким: `assets/images/имя_файла.png`
- Если страница уже опубликована, не меняйте имя `index.html` и папку публикации.
